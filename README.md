# CarBook website

Clean static-site scaffold for GitHub Pages.

## Pages

- `index.html`, `support.html`, `terms.html`, `privacy.html` — English.
- `uk/` — matching Ukrainian pages.

## Shared files

- `assets/preferences.js` — language preference and light/dark theme logic.
- `assets/style.css` — neutral page scaffold.
- `assets/site-header.css` — shared header and navigation.
- `assets/app-icon.png`, `assets/app-logo-transparent.png` — retained brand identity.

The previous landing-page design, screenshots, widget images, CarPlay image, and landing-only styles were intentionally removed so the site can be rebuilt from scratch.
